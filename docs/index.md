# Home
Welcome to Klean, a database back-up cleaner designed to help you save time, space and money by automating the deletion
of back-ups that are no longer needed. Klean works by analyzing your backup history and deleting old backups 
based on your retention policy.

Klean is designed to be easy to use, set up one time and forget. It's a hassle-free solution that requires minimal 
maintenance.
